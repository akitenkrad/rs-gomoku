# 遊び方

## ルール

2 人が交互に N × N の盤の交点へ石を置きます．先手が **黒**，後手が **白** です．縦・横・斜めのいずれかに自分の石を 5 つ先に並べた方が勝ちです．先に盤が埋まったら引き分けです．

| ルール | 勝ちになる条件 |
|---|---|
| 自由（既定） | 5 つ **以上** 並べば勝ち |
| 標準 | **ちょうど** 5 つ並べば勝ち．6 つ以上の連（長連）は勝ちにならず，対局が続く |

連珠の禁じ手（黒の三三・四四・長連の禁止）は実装していません．

## 盤のサイズと座標

盤は 7 × 7 から 19 × 19 まで選べます（既定は 15 × 15）．

- タイトル画面の `z` で選ぶ（9，11，13，15，19）か，`--size <N>` を付けて起動すると 7〜19 の任意のサイズにできます．
- 交点は列の文字（左から `a`，`b`，…）と行の数字（**上** から `1`，`2`，…）で表します．例えば `h8` は 15 × 15 の盤の中央です．`i` を含めてすべての文字を使います．

## 対局の開始

`rs-gomoku`（または `cargo run --release`）を実行するとタイトル画面が開きます．

| キー | 設定 | 値 |
|---|---|---|
| `d` | 難易度 | やさしい / ふつう / つよい |
| `f` | 先手（黒を持つ） | あなた / CPU |
| `r` | ルール | 自由 / 標準 |
| `z` | 盤のサイズ | 9 / 11 / 13 / 15 / 19 |
| `l` | 言語 | English / 日本語 |
| `Enter` / `Space` | 開始 | |
| `q` | 終了 | |

同じ設定は起動オプションでも指定できます．

```sh
rs-gomoku --size 19 --rule standard --lang ja
```

## 対局中の操作

| キー | 動作 |
|---|---|
| `←` `↑` `↓` `→` | カーソルを動かす |
| `Enter` / `Space` | カーソルの位置に石を置く |
| `h` | ヒント: 探索が最もよいと判断した手を強調表示する |
| `e` | 評価パネルの表示切替 |
| `s` | 現在の対局を棋譜ファイルに保存（[リプレイ](replay.ja.md) を参照） |
| `n` | 新しい対局 |
| `t` / `Esc` | タイトルへ |
| `q` / `Ctrl-C` | 終了 |

直前の手は強調表示され，置いた石はふわりと現れます．CPU は別スレッドで探索するので，考えている間も画面のアニメーションは止まりません．選んだ点を一瞬強調してから石を置きます．勝負がつくと勝ちラインが点滅し，あなたが勝つと紙吹雪，負けると雨が降ります．サイドパネルには，このセッションの勝・敗・分を表示します．

## 評価パネル

`e` を押すと，手番側から見た局面を分析します．盤上の候補点がヒートマップのように色付けされ，サイドパネルに上位 5 手が並びます．

- **勝ち n** / **負け n** — 探索が勝敗を **証明できた** 手．この手を含めて `n` 手で終局します．
- **+120**，**−40** など — 証明できなかったときのヒューリスティックな評価値．大きいほど手番側に有利です．

五目並べはここで解き切れるほど小さくないので，ほとんどの手は勝敗ではなく評価値で表示されます．評価値の計算方法は [戦略と探索](strategy.ja.md) を参照してください．

## 表示言語

画面の表示は既定で英語です．タイトル画面で `l` を押すか，`--lang ja` を付けて起動すると日本語になります（`replay` でも使えます）．

## 端末の要件

必要な端末サイズは盤の大きさで変わります．幅は `3N + 42`，高さは `N + 12`（最低 24．評価パネルを開くと最低 27）です．

| 盤 | 端末 |
|---|---|
| 9 × 9 | 69 × 24（パネル表示時 69 × 27） |
| 15 × 15 | 87 × 27 |
| 19 × 19 | 99 × 31 |

小さいと，広げるよう案内が出ます．True Color（24bit）対応の端末を推奨します．日本語環境で罫線の幅が崩れる場合は，端末の「East Asian Ambiguous 文字の幅」を 1（半角）に設定してください．
